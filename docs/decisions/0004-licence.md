# 0004: Licence

**Status:** proposed (2026-11-18), to be confirmed by J.

Apache-2.0: the licence of Podman, Buildah and most of the containers ecosystem, so code can be
proposed upstream (W7) without relicensing. It includes a patent grant. MIT was the alternative
(simpler, no patent grant); AGPL or other copyleft would get in the way of upstreaming.
